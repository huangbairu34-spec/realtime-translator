# 实时翻译软件

观看 YouTube 等外语直播时，实时抓取系统播放声音 → 本地 Whisper 识别 → 大模型翻译 → 悬浮字幕条显示译文。

**技术栈**：系统音频回环采集（soundcard）· 本地语音识别（faster-whisper + CUDA）· 大模型翻译（OpenAI 兼容接口）· 悬浮字幕（PyQt6）

---

## 实时性优化说明（重要）

本软件采用**流式增量架构**，不做"等整句说完"的批处理，因此延迟很低：

| 环节 | 旧方案（批处理） | 当前（流式增量） |
|---|---|---|
| 识别方式 | 等整句 + 静音判定后才识别 | 每 0.9s 对正在说的话做增量识别 |
| 翻译方式 | 一次性等完整响应 | 流式逐字上屏 |
| 首字延迟 | 2~5 秒 | **约 0.3~1 秒** |
| DeepSeek 翻译 | 2.09 秒（实测） | **首字 0.588 秒**（实测） |

**实测数据**：
- 首字延迟（说话→首个字幕）：约 **319 ms**
- 定稿延迟（说完→锁定译文）：约 **980 ms**（含识别+翻译）
- DeepSeek 流式首字：**588 ms**，一次性翻译：2090 ms

### 如果还是觉得慢，按这个顺序调
1. **换小模型**：设置→识别→Whisper 模型选 `small` 或 `base`（`medium` 精度高但慢 2~3 倍）
2. **降识别间隔**：设置→识别→识别间隔，从 900ms 调到 500ms
3. **降句末静音**：设置→识别→句末静音判定，从 350ms 调到 250ms
4. **确认流式开启**：设置→翻译→勾选"流式翻译"和"增量预览翻译"

## 一、首次使用（3 步）

### 1. 配置翻译 API
双击 **`启动.bat --debug`**（或首次运行后右键字幕条 → 设置），进入「翻译」标签页：
1. 服务商预设选 **DeepSeek**（推荐，便宜且中文好）或任意 OpenAI 兼容服务
2. 填入你的 **API Key**
3. 点「测试连接」确认可用

> 支持的预设：DeepSeek / OpenAI / 硅基流动 / 通义千问 / Moonshot，也可自定义任何 OpenAI 兼容地址。

### 2. 选择音频设备
「音频」标签页选择你的**扬声器/耳机**（回环设备），即直播声音输出端。
默认已列出系统所有输出设备的回环版本，带 `[默认]` 的是当前默认播放设备。

### 3. 选择识别模型（可选）
「识别」标签页默认 `small`。你的 RTX 4060 8G：
- `small` — **默认，速度优先，实时性最好**
- `medium` — 更准，但慢 2~3 倍
- `large-v3` — 最准，显存占用高，延迟最大

## 二、日常使用

1. 双击 **`启动.bat`** → 屏幕底部出现半透明字幕条，同时弹出**对话记录窗口**
2. 打开 YouTube 直播，正常播放
3. 字幕自动出现：上方浅色小字为**原文**，下方白色大字为**译文**

### 两个窗口

**① 悬浮字幕条**（覆盖在画面上，只看最新一句）
- **拖动**：按住字幕条任意位置拖动
- **调字号**：鼠标滚轮在字幕条上滚动
- **右键**：开始/暂停、清空、鼠标穿透、设置、退出

**② 独立对话记录窗口**（完整历史，可回看）
- 实时滚动显示所有记录：`时间戳 · 原文 · →译文`，并标注源语言
- 工具栏：**开始/暂停 · 清空 · 导出 TXT · 设置**
- **导出 TXT**：把整场翻译记录保存到桌面，方便事后回看整理
- **右键**：复制选中 / 复制全部 / 开关"自动滚动到最新"
- 点右上角 × 只是**隐藏**窗口（不退出），可从托盘菜单重新打开
- 托盘菜单 →「显示 / 隐藏对话记录」

### 系统托盘
双击托盘图标可开始/暂停；右键有完整菜单（含显示/隐藏记录窗口、设置、退出）。

## 四、常见问题

**Q：字幕一直不出现？**
- 确认「音频设备」选的是正在播放声音那个设备的**回环版**（如 `耳机 (WH-1000XM6)`）
- 确认直播有声音、系统音量没静音
- 看 `logs/app.log` 有无报错

**Q：GPU 不生效（日志显示回退 CPU）？**
已预装 `nvidia-cublas-cu12` / `nvidia-cudnn-cu12`。若仍失败，检查 `nvidia-smi` 驱动版本 ≥ 525。

**Q：延迟太高？**
- 按上面"实时性优化说明"调节；确认流式已开启
- 换小模型（`small`/`base`）
- 减小设置里的"识别间隔"和"句末静音判定"

**Q：翻译报错/额度不足？**
设置面板「测试连接」查看具体错误，确认 Key、模型名、余额。
注意 DeepSeek 官方模型名是 `deepseek-chat`（不是 deepseek-flash）。
